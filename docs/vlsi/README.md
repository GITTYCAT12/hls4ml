# VLSI / Hardware Acceleration Studies

This section contains independent hardware-oriented documentation and experiments built around the hls4ml flow.

## Current study

- [HLS → RTL → Synthesis Workflow](hls-to-rtl-synthesis.md)

## Engineering focus

- RTL generation and inspection
- HLS scheduling and microarchitecture
- FPGA resource utilization
- Timing and critical-path analysis
- Latency and initiation interval
- Fixed-point arithmetic
- Pipeline and parallelism trade-offs
- Reproducible synthesis results

The purpose is to study how high-level architectural decisions affect synthesized hardware implementation and PPA characteristics.
